# 登山計画書メーカー

信州大学 山歩会の登山計画書を、Web上で作成するプロトタイプです。

## 現在できること

- Carbon Design System (`@carbon/react`) を使った4ステップUI
- 実施日、集合場所・時間、山名、山域、企画者、留守本部などの手動入力
- YAMAPの計画データ・行程スクリーンショットを複数追加
- Tesseract.jsによるブラウザ内OCR
- 距離、上り、下り、合計時間の抽出
- 行程の時刻・地点名の抽出と編集
- 「分岐」を提出用行程から初期状態で省略
- 各地点への休憩追加と、それ以降の予定時刻の自動繰り下げ
- YAMAPスクリーンショットからルート部分を切り抜いて計画書に配置
- 元Wordテンプレートの3ページ構成に合わせたA4プレビュー
- ブラウザからPDF生成
- 元のWordテンプレートを同梱

## 開発

```bash
npm install
npm run dev
```

テスト:

```bash
npm test
```

ビルド:

```bash
npm run build
```

## 初回プロトタイプの範囲

現時点のPDFは、Wordファイルそのものをサーバーで変換するのではなく、Wordテンプレートの項目・3ページ構成をWeb上に再現してブラウザでA4 PDFとして生成します。

YAMAPのOCRは必ず確認画面を挟み、誤読を修正してからPDFに反映する設計です。OCR精度やWordテンプレートとのレイアウト差は、実際のスクリーンショットで検証しながら詰める前提です。
